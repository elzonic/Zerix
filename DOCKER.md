# Self-Hosting Zerix with Docker

If you have a VPS or a local machine with Docker installed, you can run Zerix without installing Python manually.

## Quick Start

1. Clone this repository:
   git clone https://github.com/elzonic/Zerix.git
   cd Zerix

2. Build and start the container:
   docker compose up -d

3. Access the Dashboard:
   Open http://localhost:8000 in your browser.

## Stopping the container
docker compose down
