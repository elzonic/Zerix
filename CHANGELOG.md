# Changelog

All notable changes to this project will be documented in this file.

## [0.6.0] - 2023-11-02
### Added
- Dedicated API Keys page in the Dashboard.
- Multiple API Keys support per user (Database restructure).
- Generate, Delete, and "Current Session" protection for API Keys.
- Full SaaS onboarding flow (Register -> API Key display -> Login).

## [0.5.0] - 2023-11-01
### Added
- Full SaaS Dashboard UI with modern dark mode.
- Interactive HITL (Approve/Reject) directly from the dashboard.
- SQLite Database integration and basic API Key auth.
