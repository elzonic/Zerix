Zerix is the fail-closed middleware that sits between your autonomous AI agents and the blockchain. Enforce spending caps, allowlists, and human approvals in real-time.

Start Building Live Demo

Fail-Closed Security

If a policy evaluation fails, the transaction is automatically DENIED. Prompts can be manipulated; Zerix's code cannot.

Human-in-the-Loop

Set a strict threshold. If an agent attempts to spend more, Zerix intercepts it and holds the transaction for manual approval.

Web3 & x402 Native

Built for EVM chains. Allows agents to automatically pay for API access (HTTP 402) and execute EIP-1559 transactions safely.
